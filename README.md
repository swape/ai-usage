# AI Usage

An Astro starter for an AI usage calculator, using TypeScript and plain CSS.
The calculator itself has not been implemented yet.

## Getting started

Use Node.js 22.23.4 or newer, then run:

```sh
npm install
npm run dev
```

Open the local URL printed by Astro.

## Commands

- `npm run dev` starts the development server.
- `npm run build` builds the site into `dist/`.
- `npm run preview` previews the production build.

## Project structure

- `src/pages/` contains Astro routes.
- `src/styles/global.css` contains plain CSS.
- `public/` contains static assets.
- `tsconfig.json` configures strict TypeScript support.

See the [Astro documentation](https://docs.astro.build/) for more information.
